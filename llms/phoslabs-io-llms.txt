# Phos Labs

> Behavioral science and commerce intelligence for AI agents: diagnose funnel drop-off, redesign checkout flows, rewrite copy, optimize pricing and detect cognitive biases. Delivered as a Bearer-key REST API at https://phoslabs.io/api/v1 and a hosted, OAuth 2.1-gated MCP server at https://mcp.phoslabs.io/mcp. Prepaid credits (1 credit = EUR 0.01); every response reports credits_remaining.

Generated by API Evangelist on 2026-09-19 from the provider's published OpenAPI, live tool listing, discovery documents and README; Phos Labs publishes no llms.txt of its own (https://phoslabs.io/llms.txt returns 403, https://mcp.phoslabs.io/llms.txt 404). Nothing here was invented: every URL below was fetched and every operationId exists in the spec.

## APIs

- [Behavioral Science API (REST)](https://phoslabs.io/api/v1/openapi.json): OpenAPI 3.0.3, 7 operations. Base URL https://phoslabs.io/api/v1. Auth: `Authorization: Bearer <api_key>` on every POST; `GET /api/v1/tools` is anonymous.
- [Phos Labs MCP server](https://mcp.phoslabs.io/mcp): Streamable HTTP, OAuth 2.1 (authorization code + PKCE S256, dynamic client registration, scope `claudeai`). Legacy SSE at https://mcp.phoslabs.io/sse takes an API key as the Bearer token. `tools/list` requires a token.

## Operations (REST)

- `GET /api/v1/tools` (listTools) — anonymous; returns every tool with its endpoint, credit price in EUR and input fields.
- `POST /api/v1/audit` (audit) — full behavioral audit of a product. 0 credits. Body: product_description (required), url, industry, goal.
- `POST /api/v1/diagnose` (diagnose) — diagnose funnel drop-off. 10 credits. Body: funnel_description (required), data, industry.
- `POST /api/v1/fix-checkout` (fixCheckout) — redesign a checkout or decision flow. 30 credits. Body: checkout_flow (required).
- `POST /api/v1/copy` (copy) — rewrite copy with behavioral principles. 20 credits. Body: draft, goal (both required).
- `POST /api/v1/pricing` (pricing) — pricing strategy with anchoring and decoys. 25 credits. Body: product (required), context, persona.
- `POST /api/v1/detect-biases` (detectBiases) — detect cognitive biases in text. 8 credits. Body: text (required).

Responses: `{"success": true, "result": {...}, "credits_remaining": n}`; errors: `{"error": "...", "credits_remaining": n|null}` with 401 (missing/invalid key) or 402 (insufficient credits). No Idempotency-Key: a retried POST is billed again.

## Getting a key

- `POST https://phoslabs.io/api/trial` with `{"email": "...", "name": "..."}` issues a trial key (per the tool listing). New accounts get free starter credits.
- [Buy credits](https://phoslabs.io/credits): Starter EUR 5 / 500, Standard EUR 20 / 2,000, Pro EUR 100 / 10,000 (Stripe).
